傾斜つき割り勘・飲み会の幹事に

役職や年次に合わせて、傾斜をつけて割り勘するツールです。
1次会・2次会ごとに参加者と傾斜を変えられるので、途中から来た人や先に帰った人がいても、そのまま計算できます。金額は100円単位でそろえ、LINEで送る文面まで作れます。登録もアプリも不要です。

使い方を見る
手軽に使うために

ホーム画面に追加すると、アプリのようにアイコンからすぐ開けます。入力も消えにくくなります。

    くわしい手順

    運試しモード：払う金額を、いつもの金額の0.5〜1.5倍の範囲でランダムに決めるモードです。入力は通常モードと共通で、いちばん下の「運試し」で回します。

    メンバー

    ランク1の人がいちばん多く払い、数字が大きいほど少なくなります（1〜7）。
    例：部長は1、課長は2、一般社員は3。同じ立場の人は同じランクに。

    使い方
    
    
      
      
    1. メンバーを入れる名前とランクを選び、幹事に印をつけます。ランクは1がいちばん多く払い、数字が大きいほど少なくなります（1〜7）。役職や年次が上の人ほど小さい数字に、同じ立場の人は同じランクにします。名前は空欄でもかまいません。
      2. 
      
    2. お会計を入れる1次会、2次会…と回を足して、請求額を入れます。来なかった人はチェックを外します。傾斜は「平等・弱・中・強」から選べます。
      3. 
      
    3. LINEで送る「精算」に1人ずつの金額と送る文面が出ます。「LINEで送る」かコピーして、グループに貼り付けます。支払い方法や期限は「文面を編集」で入れられます。
      4. 
    
    
    
    
      
    運試しモード お楽しみ機能
    
      
    画面上のタブを「運試しモード」に切り替えると、払う金額をくじで決められます。1人ずつ、いつもの金額の0.5〜1.5倍の範囲でランダムに決まります（いつも5,000円の人なら、2,500〜7,500円のどこか）。
    
      
    全部の回をまとめて回すか、1次会・2次会と回ごとに回すかを選べます。運試しすると、送る文面もその金額になります。通常モードに戻せば、いつもの金額の文面に戻ります。
    
      
    
    
    
    
    補足：ことばの説明
    
    
    読まなくても使えます。気になったときにどうぞ。
    
    
    
      
    傾斜
    役職や年次によって、払う金額に差をつけることです。「平等」は全員同じ、「弱・中・強」の順に差が大きくなります。「中」なら、ランクが1つ違うと1人あたりの金額が約1割違います。
    
      
    ランク
    払う金額の多さの段階です。1がいちばん多く払い、数字が大きいほど少なくなります（1〜7）。
    
      
    端数
    1人あたりの金額は100円単位で切り捨てます。余りは上のランクから順に、そのランクの全員に100円ずつ配ります。上のランクを追い越してしまう場合や、全員に配れない場合は配らず、残った分（端数）は「端数を持つ人」が払います。ふだんは幹事ですが、回ごとにほかの人にも変えられます。微調整をしなければ、ランクごとの1人あたりの金額は、上のランクほど多くなります。端数を持つ人は、端数の分だけ同じランクの人より多く払います。
    
      
    微調整
    各回の「ランクごとの金額・微調整」で、ランクごとの1人あたりの金額を100円単位で増やしたり減らしたりできます。増減した分は、端数を持つ人の支払いで合わせます。人数・ランク・幹事・請求額・参加者・傾斜・端数を持つ人を変えると、その回の微調整はリセットされます。
    
      
    保存
    入力はこのブラウザに自動で保存され、端末の外には送信しません。iPhoneのSafariでは、しばらく開かないと消えることがあるので、ホーム画面に追加しておくと安心です。「入力例で試す」で入力例を表示している間は保存しません。ページのいちばん下の「この端末の入力をすべて消す」で、保存した内容を消せます。
    
    
    
    
    
      
    手軽に使うために：ホーム画面に追加する
    
      
    ホーム画面に追加すると、アプリのようにアイコンからすぐ開けます。iPhoneでは、しばらく開かなくても入力が消えにくくなります。
    
      
    
      
    
        
    Safariで開いてください。LINEの中で開いた場合は、メニューの「Safariで開く」で開き直してから始めます。
    
        
    1. 画面下の共有ボタン（四角から上向きの矢印）を押す。見当たらないときは「…」から「共有」
    2. 一覧から「ホーム画面に追加」を押す（下にスクロールすると出てきます）
    3. 右上の「追加」を押す
    4. ホーム画面にアイコンができたら完了。次からはここから開けます
    
      
    
      
    
        
    Chromeで開いてください。LINEの中で開いた場合は、メニューの「ブラウザで開く」で開き直してから始めます。
    
        
    1. 右上の︙（メニュー）を押す
    2. 「ホーム画面に追加」（または「アプリをインストール」）を押す
    3. 「追加」（または「インストール」）を押す
    4. ホーム画面にアイコンができたら完了。次からはここから開けます
    
      
    
      
    画面の見た目は、OSやブラウザのバージョンによって少し違うことがあります。
