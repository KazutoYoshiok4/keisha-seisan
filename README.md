# 傾斜つき精算ツール v0

会社の飲み会の幹事向けの、スマホで操作できる日本語の精算ページです。ログイン・サーバ通信・外部ライブラリ・外部フォントは使いません。

## 起動と使い方

1. `index.html` をブラウザで開きます。計算ロジックも含めた1ファイルで動くため、このファイルだけを送ったり置いたりすれば使えます。ビルドやインストールは不要です。
2. メンバーを登録します。名前は任意で、空欄はメンバー順に A、B、…、Z、AA… になります。ランクは支払いの多さの段階（1〜7）で、1が最も多く払い、数字が大きいほど少なくなります。役職や年次の順に、上の人ほど小さい数字にします。画面のメンバー欄には「ランクは1が多め、7が少なめ。同じ立場なら同じランクに。」と短く表示し、詳しい説明はページ下部の「使い方」にあります（見出しの下の「使い方を見る」で移動、「ツールに戻る」で上へ戻ります）。幹事を1人選びます。メンバーの「削除」ボタンでその人を削除します。
3. 回ごとに名前（初期値は「1次会」など。「焼肉」のように変更可）と請求額（円単位の整数）を入力し、不参加の人のチェックを外します。新しい回と追加メンバーは全回参加が初期値です。新しい回の名前は、既存の「○次会」の最大番号の次になります。請求額はカンマ付き・全角数字・「円」付きの入力も可能で、0〜999,999,999円です。入力欄から離れると「35,038」のように桁区切りで表示します。
4. 傾斜を「平等／弱／中／強」から選びます。まとめて設定する欄で強さを選び、「全回同じ傾斜にする」を押すと一括適用します。この欄の値は保存され、新しく追加する回の傾斜にもなります。
5. 必要に応じて各回の「ランクごとの金額・微調整」を開き、各ランクの「＋100円／−100円」で、同ランクの1人あたりの金額を微調整します。条件を満たさないボタンは無効になります。微調整で増減した分は、同じ回の差額担当者の支払いで相殺されます。そのため、回ごとの合計は常に請求額と一致し、ずれが次の回や全回合計に持ち越されることはありません。微調整があると「調整の内訳」に、ランクごとの増減と差額担当者の支払いの増減が表示されます（例：ランク2 −100円×3人＝−300円 → 差額担当の支払いが＋300円）。
6. 「精算」の表で個人合計（名前のすぐ右）と回別金額を確認します。その下に「送る文面」がそのまま表示されます。「LINEで送る」を押すとLINEの共有画面（`https://line.me/R/share?text=…`）が開き、送り先を選べます。「コピー」で貼り付け用テキストをコピーすることもできます。「文面を編集」を開くと、はじめのあいさつ・支払い方法・支払い期限・締めのあいさつを入力できます（入力内容は保存されます）。支払い方法と期限は空欄なら文面に載せません。文面は幹事からの丁寧な連絡の形で、参加者ごとの金額（参加した回の内訳つき）とお会計の内訳を載せます。コピーに失敗すると選択可能な文面が表示されます。

各回の「差額を持つ人」で、差額担当者を「幹事」か「その他」から選びます。

- 見出しには、その回の差額（差額担当者が自分のランクの金額より多く払う分）を「差額を持つ人（差額 ＋85円）」のように表示します。
- 初期値は「幹事」です。「その他」を選ぶとプルダウンが出て、その回の幹事以外の参加者から選べます。プルダウンの初期値は、最も上位のランク（数字が最小）の人です。同ランクならメンバー一覧で先の人になります。
- 幹事が不参加の回は「幹事」を選べず、「その他」になります。自分で選んでいない間は、上と同じ最上位ランクの人が自動で担当になり、参加者やランクが変わると自動で選び直します。
- 「その他」で選んだ人がその回に参加しなくなると、初期値（幹事。幹事も不参加なら最上位ランクの人）に戻ります。ほかの参加者・ランク・幹事を変えても、選んだ人は維持します。

メンバーの追加・削除・ランク・幹事の変更は全回の微調整をリセットします。請求額・参加者・傾斜・差額担当の変更はその回の微調整をリセットします。名前変更ではリセットしません。各回の「この回の微調整を解除」で、その回の微調整だけを解除できます。回はすべて削除してもよく、その場合は新しい回を追加するまで結果は出ません。回を削除しても、残った回の名前は変わりません。

メンバーや回を削除すると、画面下に「取り消す」が出ます。押すと削除の直前（微調整を含む）に戻ります。別の変更をすると取り消しは消えます。

入力はブラウザの `localStorage` に保存します。保存できない環境でも、現在の画面での計算は継続できます。保存データはブラウザ・端末ごとで、他の端末とは共有しません。全回の入力が有効になると結果とコピーが使えます。

- 読み込めない保存データは、新規開始で上書きする前に `keisha-settlement-v0-unreadable-backup` に退避します。
- 保存済みの微調整が計算できない状態だった場合は、その回の微調整だけを解除し、画面で通知します。
- 同じ保存領域を開いている別タブで保存されると、その内容を取り込みます。古い画面の状態で上書きしないためです。

## 計算ルール

- 段階数 `N` は、全メンバーに設定された最大ランクです。その回に不参加でも `N` の決定に含みます。ランクに欠番があっても詰めません。
- ランク `r` の重みは `1 + s × ((N + 1) / 2 − r)`。`s` は平等0、弱0.05、中0.1、強0.2です。
- 各回の基準額は `請求額 ÷ その回の参加者の重みの合計` です。
- 各ランクの通常額は `基準額 × ランクの重み` を100円単位で切り捨てた金額です。
- 切り捨てで出た余り（`請求額 − 全参加者の切り捨て後の合計`）は、上位ランク（数字が小さい順）から、そのランクの参加者全員に＋100円ずつ配ります。差額担当者も、自分のランクの人数に含めます。
  - そのランク全員に配るには余りが足りない場合、そのランクは飛ばして次のランクへ進みます。
  - 配ると上位ランクの金額を追い越す場合も、そのランクは飛ばします。
  - 各ランクに配るのは1回の計算で最大＋100円です。配りきれなかった残りは差額担当者が持ちます。
- ランクごとの微調整は、余りを配ったあとの金額に加えます。
- 差額担当者は、回ごとに「差額を持つ人」で選んだ人です（初期値は幹事）。差額担当者以外は、そのランクの調整後の金額を払います。差額担当者は `請求額 − それ以外の人の合計` を払います。差額担当者には通常額を別途加算しません。
- 差額担当者の支払額が、その人のランクの調整後の金額を下回る操作は禁止です。同ランクの他の参加者がいない場合も適用します。各ランクを0円未満にする操作も禁止です。
- 差額担当者のランクを微調整すると、同ランクの他の参加者の金額と、差額担当者の下限が変わります。担当者の支払額自体は常に残額です。
- 個人の合計は参加した回の支払額の合計。不参加は表では「—」で、0円参加とは区別します。
- 内部では重みを200倍した整数で扱い、切り捨ての境界で浮動小数点誤差が出ないようにしています。

## 例1の再現手順

「例を見る」で以下の設定・微調整を入力済みにします。「例を閉じる」でもとの入力に戻せます。例の表示中は保存しないため、ページを閉じたり再読み込みしたりしても、保存済みの元の入力は残ります（例に加えた変更は残りません）。手動で再現する場合は、先に人数・ランク・参加者・傾斜・請求額を設定し、最後に微調整してください。

- A・B・H：ランク1、C・D・I：ランク2、E・F・G：ランク3。幹事はE。
- 1次会：35,038円、A〜Gが参加、傾斜は「中」、調整なし。
- 2次会：57,685円、全員参加、傾斜は「中」。ランク2を−100円、ランク3を＋100円。
- 3次会：24,500円、A・B・E・F・G・H・Iが参加、傾斜は「平等」、調整なし。

## 抽選モード

画面上部のタブで「通常モード」と「抽選モード」を切り替えます。メンバーと回の入力は両方で共通で、「3.」の欄とLINEの文面だけが変わります。

- 1人ずつ、**いつもの金額（傾斜で計算した金額）の0.5〜1.5倍**の範囲で、金額をランダムに決めます。合計は請求額と同じです。100円単位にそろえ、100円に満たない端数だけ差額を持つ人が持ちます。100円単位にそろえる分だけ、範囲から少しはみ出すことがあります。
- 抽選のしかたは2つです。
  - **全部の回をまとめて**：全回の合計を一度に抽選します。端数は幹事（幹事が払わない場合は、いつもの金額が一番多い人）が持ちます。
  - **回ごと**：各回のカードで「抽選する」を押します（2回目からは「もう一回」）。端数はその回の「差額を持つ人」が持ちます。抽選していない回はいつもの金額のままで、全部の回の合計も表示します。
- 画面には「抽選○回目」と、いつもの金額との差を出します。みんなの前で回す前提です。
- 抽選モードでは、LINEの文面も抽選の金額になります。まとめての場合は「（いつもは○円）」を、回ごとの場合は「1次会・2次会を抽選で決めました。」と回別の内訳を載せます。抽選するまでは「LINEで送る」と「コピー」は押せません。通常モードに戻すと、いつもの文面に戻ります。
- 結果は保存されます。請求額・参加者・ランクなどを変えて、いつもの金額が抽選したときとずれると、その抽選結果は取り消されます（回ごとの場合は、その回だけ）。「元に戻す」で、いつもの金額に戻ります。
- 乱数はブラウザの `crypto.getRandomValues` を使います。

## ファイルと検証

- `index.html`：画面、操作、保存、LINE用のコピーと共有リンク、使い方。外部リソースの取得や送信なし（「LINEで送る」を押したときだけLINEのページを開きます）。
  - 計算ロジックは `index.html` 内の `<script id="settlement-calc">` にあります。DOM・ストレージに依存せず入力を変更しない純粋な計算関数で、ブラウザでは `SettlementCalc` として利用します。
- `test.js`：Node標準のassertだけを使用。`index.html` から計算ロジックのブロックを取り出して検証します。
- `README.md`：この説明書。

```sh
node test.js
```

例1の全回・全員・個人合計、余りの配分（上位ランクを追い越さないことを含む）、微調整の下限、幹事不参加時の選択、1人参加、0円、入力エラー（型の不正を含む）、特殊なメンバーID、全強度・参加パターンの合計一致、抽選の合計一致と金額の範囲を検証します。画面操作（保存・例の読み込み・削除の取り消しなど）は `test.js` の対象外です。

## v0の範囲

集金済み管理、飲酒の有無、複数人の立て替え、端末間同期は未実装です。公開・デプロイは行っていません。スマホでのローカルHTMLの開き方やクリップボードの許可はOS・ブラウザに依存します。保存できない場合や自動コピーできない場合は、画面内の案内・手動コピーで継続できます。
